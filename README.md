# toukeiコマンド
![test](https://github.com/VitaAge/robosys2026kadai/actions/workflows/test.yml/badge.svg)

標準入力から読み込んだ数値データの基本統計量（個数・合計・平均・中央値・最小値・最大値・標準偏差）を計算して出力するLinuxコマンドです。

必要なソフトウェア
Python
テスト済みバージョン: 3.10〜3.14
テスト環境
Ubuntu 24.04 LTS

## インストール方法
```bash
git clone [https://github.com/](https://github.com/)VitaAge/robosys2026kadai.git
cd robosys2026kadai
chmod +x toukei
